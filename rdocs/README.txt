# Projeto MLG

## Como rodar este projeto pela primeira vez

1. Clone este repositório.
2. Abra o arquivo `MLG.Rproj` (ou `template.Rproj`) no RStudio.
3. O `renv` será ativado automaticamente. **Aceite a restauração** quando ele perguntar, 
ou execute `renv::restore()` no console.
4. Após a restauração, todos os pacotes necessários estarão instalados nas versões corretas.

**Se você pular o passo 3**, os scripts falharão com erros de "pacote não encontrado". Nesse caso,
basta rodar `renv::restore()` manualmente.
